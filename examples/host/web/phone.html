Tap Start camera, then tap the object you want the arm to reach.
How to use
  1. Print the tag at 100 % (make_tag.py) and tape it flat on the worktop; measure the black square.
  2. Tap the target on the preview. The crosshair is what the host will use.
  3. Capture. The tag must be visible in the same frame as the target.
  4. On the host: locate_target.py, then plan_to_target.py in the Pinocchio container.
