Tap Start camera, keep the base tag in frame, then tap the table to place numbered markers. Drag up or down on the preview to set the arm's height.
How to use
  1. Handheld (the default). The tag is taped to the side of the base. Tap the table to add a numbered marker, up to 10. Each tap is solved in the frame it was taken in, so the phone can move between markers.
  2. Height. Drag up or down anywhere in the preview: the badge next to the zoom chip is how far above the worktop the arm ends. A tap still adds a marker; only a drag changes the height. Each marker keeps the height it was tapped at, so moving the badge later affects new markers and the Reach band, not markers already placed. The arm refuses a tip below the default hover (10 cm by default), so the drag stops at that floor. The default is 10 cm.
  3. Move arm plans and runs the markers in order. Amber odd markers half-close the gripper; green even markers open it, starting fully open. The pins are projected onto the worktop and follow it while Reach is on. The arm returns to where it began. Clear marker removes the last one; Move arm is disabled with none.
  4. If the tag is not in frame a marker is refused rather than guessed. Turn the phone until it is, or switch to a fixed camera.
  5. Fixed camera (optional). Fit the rig once from the workstation's /live page (Rig), then press Camera here to switch. After that markers need no tag.
  6. Calibration mode turns the Move arm button back into Capture for checkerboard shots.
  7. Reach paints the band of table markers can be planned in, at the current height. With a fixed rig it is exact; with the base tag in view the phone locates the tag itself. It clears after a few seconds without a detection. By default Reach uses the tag pose alone; add &filter=ekf to the page URL to enable the 15-state IMU/EKF, which keeps the band turning and translating between tag frames.
  8. Printing the tag and giving the host its position: docs/base-marker.md.
