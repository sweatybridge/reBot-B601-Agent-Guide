Tap Start camera, keep the base tag in frame, then tap the table to place numbered markers.
How to use
  1. Handheld (the default). The tag is taped to the side of the base. Tap the table to add a numbered marker, up to 10. Each tap is solved in the frame it was taken in, so the phone can move between markers.
  2. Move arm plans and runs the markers in order. Amber odd markers half-close the gripper; green even markers open it, starting fully open. The arm returns to where it began. Clear marker removes the last one; Move arm is disabled with none.
  3. If the tag is not in frame a marker is refused rather than guessed. Turn the phone until it is, or switch to a fixed camera.
  4. Fixed camera (optional). Press Camera to switch, then Rig once: capture one pose, tap the tool tip in it, and let the arm sweep eight poses. After that markers need no tag.
  5. Calibration mode turns the Move arm button back into Capture for checkerboard shots.
  6. Reach paints the band of table markers can be planned in. With a fixed rig it is exact; with the base tag in view the phone locates the tag itself and the band follows the camera. It clears after a few seconds without a detection.
  7. Printing the tag and giving the host its position: docs/base-marker.md.
